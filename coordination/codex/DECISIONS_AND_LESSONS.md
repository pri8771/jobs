## Failure patterns to avoid

1. **Plan passed, product not run.** Documentation/schema/CI acceptance is not real workflow success. Use separate statuses and evidence types.
2. **Tests mirror the bug.** Hand-built rows and matching JSON can reproduce an incorrect producer/consumer contract. Positive production-constructor tests and actual DB/browser paths are essential.
3. **One tiny repair per owner prompt.** Freeze the full observed defect list, complete all allowed engineering, hand off coherent artifacts, and continue permitted independent work behind external gates.
4. **Move the goalposts.** New cosmetic preferences or future architecture do not enter the final build campaign. An actual safety/contract failure needs a bounded regression and repair, not another roadmap.
5. **Mutable identity / invented confirmation.** Profile/resume changes do not allow duplicate applications; URL text, arbitrary receipt strings, booleans and user reports are not independent external confirmation.
6. **Late access discovery.** Validate required account/host/credential/mapping/scope early with safe metadata and permitted probes. Public API read access is not write authority.
7. **Stale writer restores obsolete instructions.** Read the actual current owner scope and base SHA; resolve writer ownership before shared mutations. A queued task with an old prompt is not a new owner decision.
8. **Timer equals progress.** A heartbeat may keep publishing after a model stops. Report actual activity and deliberate review waits; do not forge elapsed time or repeat a SESSION_ONCE.
9. **More agents means more throughput.** Extra conflicting workers, branches, prompts and watch processes can increase rework. Preserve one actual implementer per current project contract and use bounded independent analysis only where useful.
10. **Cross-project authority bleed.** Jobs alias access, Social Bots posting/model grants and SwarmAI GitHub/live-run permissions do not transfer. Keep separate IDs, queues, tests, budgets, credentials, evidence and stop lines.
