# A-RESUME-OUTCOME-METRICS

- Type: analytics / specification
- Phase: post-first-app foundation
- Status: PROPOSED
- Owner: Antigravity
- Reviewer: ChatGPT
- Dependencies: immutable resume attribution, application lifecycle events
- Downstream: resume selection learning loop

## Purpose

Measure which resume families and exact versions perform best for which job types.

## Metrics

- applications
- recruiter responses
- screens
- interviews
- final interviews
- offers
- accepted offers
- time-to-stage

Slice by:
- resume family/version
- role family
- company
- source
- compensation band
- remote/hybrid/onsite
- date window

## Guardrail

Descriptive conversion differences are not automatically causal.
